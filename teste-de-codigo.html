Sobre a execução de PHP

PHP roda no servidor, não no navegador — por isso não é possível executá-lo diretamente aqui. Este editor ajuda você a escrever e organizar o código com conforto. Para rodar de verdade, clique em "Testar em 3v4l.org" e cole o código lá, ou use um ambiente local como XAMPP, Laravel Herd ou php -S localhost:8000.
